REST API Documentation

Genea Access Control API - v1.0.0

Complete reference for the Genea Access Control platform — manage users, doors, cards, schedules, and more from your first API call to production.

REST / JSON Bearer Auth HID Hardware Mercury Hardware support: acsupport@getgenea.com
🔐
Authentication
All requests require Bearer token auth.
Include Authorization: {token_type} {api_token} and Content-Type: application/json in every request.
⚙️
Hardware Types
Genea supports HID (VertX/Alio) and Mercury (LP/EP/MR) controllers.
Mercury endpoints are prefixed with /mercury/.

Common Variables

{api_token}
Token-based authentication key for API access
{customer_uuid}
Unique identifier for your customer portal
{location_uuid}
Unique identifier for a specific location
{api_url}
Base URL for all API requests
{token_type}
Token prefix, typically "Bearer"
{user_uuid}
Unique identifier for a specific user

PUT Update User Card Access
PUT

This API will update (i.e. revoke/restore) user's card access on location level. Revoking the access at location level will suspend the user's all keys and access will not be granted to the user. Upon restoring the access, all keys will function normally.

Payload ParametersMandatory or OptionalTypeDescription
is_card_access_revokedMandatorybooleantrue = To revoke access
false = To restore access
location_uuidsMandatoryArrayList of location_uuids in which user's card access needs to be updated
Request Body
{
    "is_card_access_revoked": true/false,
    "location_uuids": ["{{location_uuids}}"]
}
